# 🔍 ImageSearch

Aplicativo frontend em React para pesquisa de imagens: o usuário digita um termo na barra de busca e são exibidas imagens relacionadas ao termo.

🔗 **Vídeo demonstrativo (upado no LinkedIn):**   
[Ver post no LinkedIn](https://www.linkedin.com/feed/update/urn:li:activity:7281088909294338049/)

---

## 🧱 Tecnologias
- ⚛️ React 19 via Create React App 
- 🎨 CSS, HTML
- 👾 API: Pexels

---

## 🚀 Funcionalidades
- Barra de busca para digitar palavras-chave
- Exibição de imagens retornadas pela pesquisa
- Thumbnails dinâmicos conforme o termo digitado

---

## ⚙️ Scripts disponíveis
```bash
npm start       # inicia o servidor de desenvolvimento (http://localhost:3000)
npm run build   # gera o build de produção otimizado
```

---

## ⚙️ Instalação e execução

### 1️⃣ Clone o projeto:
```bash
git clone https://github.com/EmersonAndrey/ImageSearch.git
cd ImageSearch
```

### 2️⃣ Instale as dependências:
```bash
npm install
```

### 3️⃣ Execute localmente:
```bash
npm start
```
Acesse: http://localhost:3000

### Ou, acesse a aplicacao em producao:
[ImageSearch](https://image-search-six-pink.vercel.app/)
